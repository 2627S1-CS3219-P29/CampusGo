## Run locally

Copy `.env.example` to `.env`, set `DATABASE_URL`, then initialize the database:

```bash
deno task db:init
```

Start the app:

```bash
deno task dev
```

## Prisma

- Contract: `src/prisma/contract.prisma`
- Prisma config: `prisma.config.ts`

After changing the contract, run:

```bash
deno task contract:emit
```
